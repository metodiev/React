#  React Interview Question 11: What is the difference between `useCallback` and `useMemo`?


##  Answer

Both useCallback and useMemo are performance optimization hooks in React that help avoid unnecessary re-computations or re-creations during re-renders.

However, they serve different purposes:

| Hook         | Purpose                                       | Returns       |
|--------------|-----------------------------------------------|---------------|
| useCallback| Memoizes a function*                      | A memoized function |
| useMemo    | Memoizes a calculated value               | A memoized value |

---

## useCallback – Memoize a Function

```jsx
const memoizedFn = useCallback(() => {
  // Some logic
}, [dependencies]);
```

## Example: useCallback
``` jsx
const handleClick = useCallback(() => {
  console.log('Clicked');
}, []);

```
## Without useCallback, the handleClick function would be recreated on every render — potentially causing child components to re-render too.

Example: useCallback
```jsx
const handleClick = useCallback(() => {
  console.log('Clicked');
}, []);
```

## useMemo – Memoize a Value
const memoizedValue = useMemo(() => computeExpensiveValue(x), [x]);


- Caches computed values (like filtered arrays, math calculations).
- Runs the function only when dependencies change.

## Example: useMemo

```jsx
const sortedList = useMemo(() => {
  return list.sort((a, b) => a - b);
}, [list]);
```

## Best Practices

### Use useCallback to memoize functions, especially if:

Passing them to child components

Using them in useEffect or useMemo dependencies

Use useMemo to memoize computed values, especially if:

The calculation is expensive

It avoids recalculating the same result on every render

Without useMemo, this sorting operation would happen on every render.


## Summary


| Hook          | Use When You Want To…              | Returns           |
| ------------- | ---------------------------------- | ----------------- |
| useCallback | Avoid recreating the same function | Memoized function |
| useMemo    | Avoid recalculating the same value | Memoized value    |
